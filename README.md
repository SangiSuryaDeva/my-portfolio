## Preview
Open `index.html`, or serve this folder with any static server. No framework/build step is required.

## Before publishing
1. Replace `YOUR_EMAIL@example.com` in `assets/site.js` with your preferred professional email.
2. Add your resume PDF and link if you want a resume download.
3. Replace CSS-generated illustrative interface placeholders with approved product screenshots. These placeholders are not screenshots of real products.
4. Add your own approved portrait if desired; this build does not fabricate a personal portrait.
5. Add professional social profile URLs and a favicon/social preview image.
6. Review project copy and confirm client confidentiality/permission before publication.
7. Contact form currently opens a `mailto:` draft; connect a form backend/service for server-side submissions.
8. Google Fonts are loaded externally; system fonts will be used if unavailable.

## Design
Dark charcoal and solar-gold visual language inspired by the approved Creative Sun homepage mockup; responsive navigation, case study templates, archive filters, and CSS-generated UI illustration placeholders.
